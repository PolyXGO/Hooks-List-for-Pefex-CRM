This document compiles all available Hooks (Actions & Filters) within the Perfex CRM core across different versions. It serves as an essential resource for developers to master the system, customizing layouts and features while maintaining core integrity.

🎯 OBJECTIVES:

- Provide accurate hook references for each version.
- Support the creation of complex and professional modules.
- Optimize the development and maintenance lifecycle.

This hook list has been used to develop world-class utility modules such as:

- [PolyUtilities](https://codecanyon.net/item/polyutilities-for-perfex-crm-quick-access-menu-custom-js-css-and-more/49522529): System optimization toolkit, quick access menu, custom JS/CSS.
- [FlexiNote](https://codecanyon.net/item/flexinote-for-perfex-crm/60590690): Flexible and powerful note-taking system.

- [FlexiStore](https://erp.polyxgo.com/code/project/polydemo): Digital product store, licenses, modules, and plugins system for Perfex CRM.
- FlexiBlog: Professional blog management system for Perfex.
- Poly Tour Guide Builder: Interactive user onboarding and tour system.
